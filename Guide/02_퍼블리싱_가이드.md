# 02. 퍼블리싱 가이드 (Unity 적용)

완성된 그림을 Unity 6.5 프로젝트에 넣고 화면에 조립하는 규칙이다. 아래 값은 현재 프로젝트의 임포트 설정과 에디터 스크립트에서 읽은 것이다.

## 1. 폴더 구조

```
ArtSource/                 원본 (Unity가 읽지 않음)
  Units/                   캐릭터 원본 JPG (1264×1264, 흰 배경)
  effects/                 이펙트 원본 JPG
Assets/
  Art/Sprites/
    Units/                 직업 캐릭터 프레임 PNG
    Enemy/                 적 캐릭터 프레임 PNG
    Maps/Tiles/            맵 타일
    Maps/Objects/          맵 위 오브젝트 (tower)
    UI/                    버튼, 카운터, 패널, 기호
    Effects/               이펙트 프레임, 선택 표시, 사거리
  Prefabs/UI/              UI 프리팹 (UiPrefabBuilder가 생성)
  Fonts/                   NotoSansKR + TMP SDF 에셋
  Resources/               EffectLibrary.asset
  Scripts/Editor/          HudSetup, MapSetup, UiPrefabBuilder
```

- 원본은 `ArtSource/`에, 게임에 쓰는 결과물만 `Assets/Art/Sprites/`에 둔다.
- 새 분류가 생기면 `Sprites/` 아래에 폴더를 하나 만들고 이 표에 추가한다.

## 2. 파일 이름

모두 소문자 + 밑줄(snake_case), 확장자는 `.png`.

| 종류 | 규칙 | 예 |
| --- | --- | --- |
| 직업 | `<id>_idle`, `<id>_attack1`~`4` | `archer_attack2.png` |
| 적 | `<id>_idle`, `<id>_move1`~`4` | `slime_move3.png` |
| 맵 타일 | `<이름>`, 변형은 `_1`, `_2` | `grass_2.png`, `path_corner.png` |
| 둥근 버튼 | `btn_<기능>` | `btn_pause.png`, `btn_normal_speed.png` |
| 카운터 | `counter_<대상>` (영어) | `counter_barrier.png` |
| 패널 | `panel_<모양>` | `panel_stone.png` |
| 9분할 틀 | `frame_<용도>` | `frame_card.png` |
| 기호 | `symbol_<이름>` | `symbol_plus.png` |
| 이펙트 | `fx_<상황>_<세부>_<1~4>` | `fx_combine_pick_1.png` |

- `<id>`는 밸런스 시트와 `Assets/Data/Jobs`의 직업 id와 똑같이 쓴다. 다르면 소환에 나오지 않는다.
- 프리팹 이름은 PascalCase로, 스프라이트 이름에서 만든다. `btn_normal_speed` → `Button_NormalSpeed`, `counter_barrier` → `Counter_Barrier`, `panel_wide` → `Panel_Wide`.
- 카운터 영어 이름: 마나 결정 `crystal`, 결계 `barrier`, 웨이브 `wave`, 시간 `time`, 몬스터 `monster`.

## 3. 텍스처 임포트 설정

모든 스프라이트에 공통으로 적용한다.

| 항목 | 값 | 이유 |
| --- | --- | --- |
| Texture Type | Sprite (2D and UI) | |
| Sprite Mode | Single | |
| Filter Mode | **Point (no filter)** | 픽셀아트가 흐려지지 않게 |
| Compression | **None** | 압축하면 픽셀 경계가 뭉개짐 |
| Generate Mip Maps | 끔 | |
| Max Size | 2048 | |

### 분류별 PPU와 피벗

| 분류 | PPU | 피벗 | 원본 크기 예 |
| --- | --- | --- | --- |
| 직업·적 캐릭터 | 128 (맵 타일과 같은 밀도) | 아래 가운데 근처 (0.5, 0.2) | 78×132, 124×111, 105×108 |
| 맵 타일 | 128 | 가운데 | 128×128 (타일 1칸 = 1유닛) |
| 맵 오브젝트 (tower) | 74.5 | 왼쪽 아래 (0, 0) | 149×199 |
| UI | 100 | 가운데 | 버튼 184×184, 카운터 398×216 |
| 이펙트 | 128~650 (이펙트마다 다름) | 가운데, 바닥 이펙트는 (0.5, 0.22) | 420~600px |
| 선택 표시 / 사거리 | 92 / 128 | 가운데 | 90×98 / 256×256 |

- 캐릭터와 맵 타일은 PPU를 128로 같게 둔다. 원본에서 줄일 때 키가 타일 1칸(128px) 안팎이 되게 한다.
- 캐릭터 피벗은 **발밑**에 둔다. 같은 캐릭터의 모든 프레임은 피벗을 같게 맞춘다 (슬라임은 0.198).
- 이펙트 PPU는 화면에 보일 크기에 맞춰 개별로 정한다. 새 이펙트를 넣으면 이 표에 값을 적는다.

## 4. 9-slice 패널

늘려 쓰는 패널은 Sprite Editor에서 Border를 설정하고, Image Type을 **Sliced**로 쓴다.

| 스프라이트 | 크기 | Border (L, B, R, T) |
| --- | --- | --- |
| `panel_wide` | 400×172 | 42, 42, 42, 42 |
| `panel_long` | 396×106 | 47, 47, 47, 47 |
| `panel_steel` | 398×196 | 40, 40, 40, 40 |
| `panel_stone` | 384×182 | 88, 76, 88, 76 |
| `frame_panel` | 192×192 | 64, 64, 64, 64 |
| `frame_card` | 192×192 | 64, 64, 64, 64 |

- 모서리 장식이 Border 안쪽에 들어가야 늘려도 장식이 찌그러지지 않는다.
- 조합표 9분할 틀은 큰 틀 0.4배, 탭·카드 0.3배, 재료 칩 0.2배로 쓴다.

## 5. 프리팹 만들기

UI 프리팹은 손으로 만들지 않고 메뉴로 만든다.

1. 스프라이트를 `Assets/Art/Sprites/UI/`에 넣고 3, 4번 설정을 적용한다.
2. 새 버튼·카운터·패널이면 `Assets/Scripts/Editor/UiPrefabBuilder.cs`의 이름 목록에 추가한다.
3. Unity 메뉴 **RandomDefense › UI 프리팹 만들기**를 실행한다. `Assets/Prefabs/UI/`의 프리팹을 덮어쓴다.

`UiPrefabBuilder`가 하는 일:

- 둥근 버튼(`btn_*`): Image + Button, Native Size, Preserve Aspect
- 카운터(`counter_*`): 왼쪽 아이콘 옆에 TMP 숫자 텍스트
- 패널(`panel_wide`, `panel_long`, `panel_steel`): Image Type Sliced

프리팹을 손으로 고치면 다음 실행 때 덮어써진다. 바꿀 내용은 스크립트에 넣는다.

## 6. HUD 배치

HUD는 메뉴 **RandomDefense › HUD 배치**(`HudSetup.cs`)로 `InGame` 씬에 배치한다.

### Canvas Scaler

| 항목 | 값 |
| --- | --- |
| UI Scale Mode | Scale With Screen Size |
| Reference Resolution | **1920×1080 (가로)** |
| Match Width Or Height | 0.5 |

### 현재 배치

| 요소 | 앵커 | 위치 | 크기 |
| --- | --- | --- | --- |
| 설정 / 빨리감기 / 일시정지 | 오른쪽 위 | x -20 / -130 / -240, y -10 | 100 |
| 소환 버튼 | 아래 가운데 | y +8 | 110 |
| 조합 / 취소 버튼 | 아래 | x +250 / +486 | 260 / 180 |
| 조합표 버튼 | 아래 | x -250 | 260 |
| 토스트 | 아래 가운데 | y +160 | 900×60 |
| 닫기 버튼 (조합표) | 헤더 오른쪽 | – | 77 |

- 버튼 간격은 110px(버튼 100 + 여백 10)을 기본으로 한다.
- 화면 가장자리 여백은 위 10px, 오른쪽 20px.
- 눌리는 요소는 기준 해상도에서 최소 77px 이상으로 둔다.

## 7. 글자 (TextMesh Pro)

| 항목 | 값 |
| --- | --- |
| 폰트 | Noto Sans KR Regular (`Assets/Fonts/NotoSansKR-Regular SDF.asset`) |
| 기본 색 | `#F3E6D0` |
| 외곽선 | `#1D140D`, 두께 0.2 |
| 크기 | 조합표 탭 26, 직업 이름 18~19 |

- 이미지 안에는 글자를 넣지 않는다. 버튼 라벨, 숫자, 보스 이름은 모두 TMP로 올린다.
- 새 글자가 SDF 아틀라스에 없으면 TMP Font Asset Creator로 다시 굽는다.

## 8. 상태 표현

버튼 상태는 색 틴트로 표현한다 (`GameUI.cs`).

| 상태 | Image.color |
| --- | --- |
| 기본 | 흰색 (원래 색) |

## 9. 넣기 전 확인

- [ ] 배경이 투명한가
- [ ] Filter Mode Point, Compression None인가
- [ ] PPU와 피벗이 분류 표와 같은가
- [ ] 같은 캐릭터의 프레임끼리 크기와 피벗이 같은가
- [ ] 9-slice 패널에 Border를 넣었는가
- [ ] 파일 이름이 규칙과 id에 맞는가
- [ ] 프리팹은 메뉴로 다시 만들었는가
- [ ] [필요 아트 현황](04_필요_아트_현황.md)의 상태를 바꿨는가
