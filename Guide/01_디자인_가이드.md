# 01. 디자인 가이드

모든 게임 아트(직업·적 스프라이트, 맵 타일, UI, 이펙트)는 **검사 스프라이트와 같은 픽셀아트**로 맞춘다. Canva로 에셋을 만들 때마다 같은 규칙을 다시 쓰지 않도록 화풍, 규격, 금지 규칙을 여기 모았다.

## 1. 세계관과 톤

- 균열의 탑이 무너진 판타지 세계. 차원 소환술사가 여러 세계의 직업자를 불러 몬스터를 막는다.
- 톤은 약간 가벼운 분위기다.

## 2. 기준 이미지

| 기준 이미지 | Canva 미디어 ID | 무엇을 맞추나 |

## 3. 색

색은 의미에 묶는다. 같은 의미는 어느 에셋에서나 같은 색을 쓴다.

### 의미 색

| 역할 | 색 | 쓰는 곳 |
| --- | --- | --- |
| 마나 결정 | 밝은 파랑 | 마나 결정 아이콘, 소환 버튼(차원문), 마나 결정 소품 |
| 차원 균열 · 몬스터 | 보라 | 적 출발점 균열, 몬스터 아이콘 눈 |
| 방어 결계 | 푸른 빛 | 도착점 결계 관문, 결계(방패) 카운터 |
| UI 테두리 | 어두운 나무 갈색 + 금속 장식 | 버튼, 패널 |
| 보조 테두리 | 회색 돌 | 툴팁, 누를 수 있는 버튼 패널 |
| 맵 바닥 | 초록 잔디 + 금 간 돌길 | 맵 타일 |

의미 색의 헥스값은 아직 정하지 않았다. 확정된 에셋에서 뽑아 이 표에 채운다.

## 4. 픽셀과 규격

- 픽셀 한 칸 크기와 외곽선 두께는 검사 스프라이트에 맞춘다.
- 줄일 때는 **최근접 보간(Nearest Neighbor)만** 쓴다. 다른 보간은 픽셀을 흐리게 만든다.
- 생성 단계에서는 배경을 **흰색 단색**으로 두고, 게임에 넣기 전에 지워서 투명 PNG로 만든다.

| 에셋 | 규격 | 프레임 | 비고 |
| --- | --- | --- | --- |
| 직업 캐릭터 | 원본 1264×1264 JPG, 게임 안 64px 유닛 | idle + attack 4장 | 한 방향 원본 + 좌우 반전 |
| 적 캐릭터 | 직업과 같음 | idle + move 4장 | 슬라임도 4프레임 |
| 보스 | 일반 적보다 크게 | idle + move 4장 | 프레임은 무조건 4장 |
| 이펙트 | 원본에서 잘라 냄 | 4장 (`_1`~`_4`) | 투명 PNG |
| UI 아이콘 | 32×32 캔버스, 가운데 정렬 | – | 투명 PNG |
| UI 패널 | 9-slice로 늘려 쓰는 빈 패널 | – | 투명 PNG |
| 맵 타일 | 64×64 격자 (실제 파일은 128×128, README 참고) | – | 이음새 없이 반복 |

같은 캐릭터의 프레임끼리는 위치와 크기를 맞춘다. 발 위치가 프레임마다 달라지면 게임에서 캐릭터가 흔들린다.

## 5. 컴포넌트

UI는 **빈 패널 + 아이콘 + 숫자 텍스트**를 게임에서 조립하는 게 원칙이다. 아이콘을 패널에 그려 넣은 한 장짜리 이미지는 새로 만들지 않는다.

| 컴포넌트 | 구성 | 기준 에셋 |
| --- | --- | --- |
| 카운터 (마나 결정·결계·웨이브·몬스터·시간) | 빈 패널 1종 + 왼쪽 아이콘 + 오른쪽 숫자 | UI v5 레이어 분리 카운터 패널·아이콘 |
| 둥근 버튼 (재생·일시정지·빨리감기·일반 속도·설정·닫기) | 나무 테두리 + 금속 장식 4개 + 은빛 아이콘 | UI v5, `btn_normal` |
| 소환 버튼 | 차원문 아이콘, 마나 결정과 같은 파랑 | UI v5 |
| 긴 패널 | 몬스터 수 게이지, 대화창 | UI v5 레이어 분리 긴 패널 |
| 돌 테두리 패널 | 툴팁, 누를 수 있는 버튼 | UI v5 레이어 분리 돌 패널 |
| 9분할 큰 틀 | 조합표 팝업 틀과 카드 | 원본 1538×467, 경계 64px |
| 조합표 기호 | `<` (결과 ← 재료), `+`, `?` (미발견) | 둥근 버튼 아이콘과 같은 은색 |
| 보스 이름 배너 | 돌·나무 테두리 + 붉은 보석, 가운데 빈 면에 이름 | 원본 1093×294 |

- 버튼 아이콘은 짝을 맞춘다. 빨리감기는 꺾쇠 두 개(`>>`), 일반 속도는 같은 모양 꺾쇠 하나(`>`)다.
- 새 카운터가 필요하면 아이콘 하나만 새로 만든다.
- 히든 조합의 재료 수가 드러나지 않도록 조합하기 버튼에는 고른 개수를 표시하지 않는다.

## 6. 금지 규칙

아래 항목은 어떤 에셋에도 넣지 않는다. Canva 프롬프트에는 매번 이 목록을 붙인다.

- 이미지 안의 글자·숫자·라벨·로고 (텍스트는 게임에서 올린다)
- 아이콘을 패널에 그려 넣은 한 장짜리 UI
- 픽셀아트가 아닌 그림체 (실사, 부드러운 그라데이션, 플랫 SD)
- 검사보다 두껍거나 얇은 외곽선, 더 촘촘하거나 거친 픽셀
- 의미에 맞지 않는 색 (예: 보라색 소환 버튼, 파란색 몬스터)
- 탱크·총 같은 군사 소품
- 이모지
- 관련 없는 이전 시안을 참고 이미지로 넣기 (그대로 베껴서 새 시안이 나오지 않는다)
