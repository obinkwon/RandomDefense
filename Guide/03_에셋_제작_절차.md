# 03. 에셋 제작 절차

에셋 하나를 생성부터 게임 반영까지 만드는 순서다.

## 1. 전체 흐름

1. **시안 방향 확정**: 디자인 캔버스에서 방향을 고른다.
2. **목록 정리**: 필요한 캐릭터, 타일, 버튼을 [필요 아트 현황](04_필요_아트_현황.md)에 적는다.
3. **에셋 하나씩 생성**: 아래 2절 순서대로 만든다.
4. **게임 반영**: 배경 제거 → 규격 크기로 줄이기 → Unity에 넣기 ([퍼블리싱 가이드](02_퍼블리싱_가이드.md)).
5. **현황 갱신**: 필요 아트 목록의 상태를 "완료"로 바꾼다.

## 2. 에셋 하나 만들기

1. **입력 확인**
   - 직업·적: [직업 밸런스 시트](https://claude.ai/artifact/QNzGBGJyJkFYGCwtXKBQxu)의 '이미지' 시트에서 해당 행(외형·모션·이펙트)을 먼저 본다. 행이 없으면 없다고 먼저 알린다.
   - UI: [RandomDefense 필요 아트](https://claude.ai/artifact/BjDH88WM4psFhtp5toP6Kr) 목록을 본다.
2. **참고 이미지 고르기**
   - 화풍: 검사 (`MAHbbG80J7w`)
   - UI: UI v5 (`MAHb-dJs_H8`)
   - 직업 캐릭터: 기본 몸 템플릿 (`MAHba8bU0eM`)도 함께 넣는다.
3. **하나씩 생성**: 시트 한 장에 여러 개를 모아 만들지 않는다. 흰 배경 가운데에 하나만 둔다. 프롬프트에 [금지 규칙](01_디자인_가이드.md#6-금지-규칙)을 붙인다.
4. **저장**: 결과는 디자인 캔버스에 이미지 카드, 설명, Canva 원본 링크로 남긴다. 최신을 위에 두고 이전 시안은 아래 줄로 내린다.
5. **게임 반영**: 배경 제거 → 최근접 보간으로 축소 → Unity에 넣기 → 필요 아트 목록 갱신.

## 3. 시트에서 잘라 쓸 때 주의할 점

AI로 만든 픽셀아트는 격자가 정확하지 않다.

- 픽셀 크기가 들쭉날쭉하거나 타일 경계가 살짝 어긋날 수 있다.
- 그대로 64px로 줄이면 선이 뭉개지거나, 타일을 이어 붙일 때 이음새가 보일 수 있다.

그래서 둘 중 하나로 만든다.

1. **쓸 것만 하나씩 따로 생성** (더 안정적): 예) "64×64 돌길 직선 타일 1개, 이음새 없이 반복 가능"
2. **시트에서 잘라 손보기**: 잘라낸 뒤 Aseprite 같은 픽셀 편집기에서 이음새와 외곽선을 손본다.

배경 제거는 Canva 배경 제거 기능으로 한다. 고해상도 원본은 디자인 캔버스 각 카드의 "Canva 원본" 링크에서 받는다.

## 5. 캐릭터 원본 규격

- 1264×1264 JPG, 흰 배경, 캐릭터는 화면 가운데.
- 같은 캐릭터의 프레임은 위치와 크기를 맞춘다.
- 직업: `<id>_idle.jpg` + `<id>_attack1~4.jpg`
- 적: `<id>_idle.jpg` + `<id>_move1~4.jpg`
- `ArtSource/Units/`에 넣으면 배경 제거와 크기 조정은 Claude가 한다.
