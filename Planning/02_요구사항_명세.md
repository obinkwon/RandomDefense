### 맵·배치

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| F-14 | 적은 필드의 순환 경로를 따라 이동한다. | 필수 |
| F-15 | 직업은 배치가 가능한 칸에만 배치된다. | 필수 |
| F-16 | 소환한 직업은 빈 칸에 자동으로 배치된다. 빈 칸이 없으면 소환되지 않고 토스트 메시지를 띄우며, 배치된 직업을 되팔아 마나 결정을 돌려받고 칸을 비울 수 있다. 되팔기 가격은 밸런스 시트에서 정한다. | 필수 |
| F-17 | 직업은 탭 두 번으로 옮긴다. 직업을 탭해 선택한 뒤 다른 칸을 탭하면, 빈 칸이면 이동하고 다른 직업이 있으면 자리를 바꾼다. 선택한 직업, 다른 직업, 배치가 가능한 칸이 아닌 곳을 탭하면 선택이 풀린다. | 필수 |

### 직업 소환·공격

| F-25 | 멀티 협동 퀘스트에 성공하면 마나 결정을 얻는다. | 추후 |

## 비기능 요구사항

기획서 기술 스펙(Unity 6 LTS, Unity Relay 등)을 기준으로 하며, 9개 중 6개가 필수다.

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| N-01 | 적·이펙트를 오브젝트 풀로 재사용해 후반 스테이지에서도 끊김 없이 돌아가야 한다. | 필수 |
| N-02 | 직업 스탯, 조합표, 스테이지, 소환 확률은 ScriptableObject 데이터로 분리해 코드 수정 없이 밸런스를 고칠 수 있어야 한다. | 필수 |
| N-03 | 조합 판정은 재료 ID를 정렬한 키로 조합표에서 바로 찾아야 한다. | 권장 |
| N-04 | 배속·일시정지는 Time.timeScale로 처리하고, UI 연출은 배속의 영향을 받지 않아야 한다. | 필수 |
| N-05 | 멀티는 전용 서버 없이 Unity Relay로 연결하고, 전투는 각자 기기에서 계산해 필요한 정보만 주고받는다. | 필수 |
| N-06 | Lobby·Relay 사용을 위해 Unity Authentication 익명 로그인으로 플레이어를 식별한다. | 필수 |
| N-07 | 재접속하거나 호스트가 바뀌어도 진행 중인 상태가 이어져야 한다. | 필수 |
| N-08 | 입력은 Input System 액션 단위로 만들어, PC 지원 시 터치와 마우스를 같은 코드로 처리한다. | 권장 |
| N-09 | 무료로 출시하되, 수익 모델을 나중에 붙일 수 있게 한다. | 권장 |

## 확인이 필요한 사항

기획서의 미정 사항과 요구사항을 정리하며 나온 빈칸이다. 정해지면 괄호 안 요구사항을 확정한다.

- [ ] 퀘스트·미션별 마나 결정 획득량 (F-25, F-26)
- [ ] 배치 칸 수: 6×3으로 시작, 후보 6×3 / 7×3 / 6×4 (F-15)
- [ ] PC 플랫폼(Steam 등)과 지원 시점 (F-47)
- [ ] 멀티 전용 협동 퀘스트 내용과 도입 시점 (F-43)
- [ ] 화면 구성(테스트 후 결정): 한쪽에 필드, 반대쪽에 버튼·정보 창을 약 7:3 비율로 배치하는 안. 확인할 것: 왼손잡이용 좌우 전환 설정, HUD 위치, 30% 영역에 들어갈 버튼·정보 창 배치, 노치 Safe Area, 판매 버튼 위치(좌우측 끝에 두고 테스트)
