## 세계관과 컨셉

균열의 탑이 무너진 판타지 세계에서, 차원 소환술사가 불안정한 차원문으로 랜덤 직업을 불러내 균열에서 쏟아지는 몬스터를 막는다. 스토리는 배경만 깔고, 재미의 중심은 직업 뽑기와 조합이다.

세계의 중심에는 차원의 균열을 봉인해 온 ‘균열의 탑’이 있었다. 어느 날 탑이 무너지면서 봉인이 풀렸고, 균열에서는 슬라임, 고블린, 오크 같은 몬스터가 쏟아져 나왔다.

차원 소환술사들은 이를 막기 위해 차원문을 열어 여러 세계의 직업자를 전장으로 불러내기 시작했다.

문제는 탑이 무너진 여파로 차원문이 불안정하다는 것. 차원문을 열 때마다 어떤 직업이 올지는 아무도 모른다.

그렇게 차원 소환술사들은 오늘도 차원문을 열고 몬스터를 막아 낸다.

| 항목 | 컨셉 |

### 게임 규칙과 설정

| 게임 규칙 | 설정 |
| --- | --- |
| 마나 결정 | 몬스터가 쓰러지며 남기는 결정. 차원문을 여는 연료다 |
| 소환 (마나 결정 6개) | 마나 결정을 써서 차원문을 열고 직업자 한 명을 불러낸다 |
| 소환 확률 (일반 80%·고급 19%·희귀 1%) | 강한 존재일수록 불안정한 차원문으로 끌어오기 어렵다 |
| 조합 | 소환된 직업자들의 영혼을 공명시켜 하나의 상위 직업으로 만든다 |
| 영웅 등급 (소환 불가) | 영혼끼리의 공명으로만 태어난다 |
| 히든 직업 | 특정 영혼끼리만 일어나는 특이 공명. 전설 속에만 남은 존재가 나타난다 |
| 판매 | 소환을 풀어 원래 세계로 돌려보내고 마나 결정 일부를 돌려받는다 |
| 클리어 (마지막 스테이지) | 이번 방어선은 지켜냈다 |
| 패배 (라이프 0) | 방어 결계가 완전히 무너지면 방어선이 뚫린다 |
| 라이프 (한계 초과 시 10초마다 1 감소) | 방어 결계의 내구도. 몬스터가 한계 수를 넘으면 결계가 버티지 못하고 조금씩 깎여 나간다 |
| 멀티 (최대 4명) | 여러 차원 소환술사가 방어선을 나눠 맡는다 |

### 튜토리얼로 이어지는 안내

1. 첫 소환: “마나 결정 6개로 차원문을 열어 직업자를 불러내세요.”
2. 배치: “소환된 직업자를 빈 칸에 배치하세요.”
3. 첫 몬스터 처치: “몬스터가 남긴 마나 결정으로 다시 차원문을 열 수 있습니다.”
4. 첫 조합: “직업자들의 영혼을 공명시키면 더 강한 직업이 태어납니다. 조합표를 확인해 보세요.”
