2026-11-19

> 원본: [랜덤 직업 디펜스 기획서](https://claude.ai/artifact/Y4FquX8WbZkQMVMDBZweXE) (2026-11-27에 옮김. 지금은 이 파일이 기준)

## 1. 개요

### 1.1 게임 소개

타워 대신 **직업**을 배치해 몰려오는 적을 막는 2D 디펜스 게임. 스타크래프트 유즈맵 "랜덤 디펜스"에서 따온 방식으로, 직업이 무작위로 나오고 직업끼리 **조합**하면 더 높은 등급의 직업이 나온다. 특정 조합으로만 얻는 **히든 직업**도 있다.

### 1.2 핵심 재미

- 무작위로 뽑힌 직업으로 어떤 조합을 노릴지 고민하는 재미
- 하위 직업을 모아 상위 등급·히든 직업을 만드는 성장감
- 최대 4명이 각자 플레이하면서 함께 클리어를 목표로 하는 협동

### 1.3 기본 정보

| 항목 | 내용 |
| --- | --- |
| 게임명 (가칭) | 랜덤 직업 디펜스 |
| 장르 | 랜덤 디펜스 (타워 디펜스 변형) |
| 플랫폼 | 모바일 앱 우선 (안드로이드), 이후 PC 지원 |
| 화면 | 가로 고정 |
| 플레이 인원 | 싱글 기본(오프라인), 멀티 최대 4인(온라인) |
| 수익 모델 | 무료 (추후 검토) |
| 모티브 | 스타크래프트 유즈맵 랜덤 디펜스 |
| 타깃 | 유즈맵 디펜스를 즐겼던 게이머, 짧게 반복하는 캐주얼 전략 게임 이용자 |

## 2. 게임 구조

### 2.1 진행 방식

- 스테이지 형식으로 진행하며, 스테이지마다 적이 몰려온다.
- 스테이지 **해금 방식은 없다.** 난이도를 고르면 1스테이지부터 그 난이도의 최대 스테이지까지 이어서 진행한다.
- 난이도별로 다른 점은 **최대 스테이지 수**와 **적의 강함**뿐이다.

한 판의 흐름

1. 난이도 선택
2. 마나 결정으로 직업 소환 (등급은 확률로 결정)
3. 스테이지마다 적이 나와 필드 둘레의 순환 경로를 돌고, 직업이 자동 공격
4. 직업 2~4개를 조합해 상위 등급 생성
5. 특정 조합으로 히든 직업 획득
6. 스테이지를 클리어하며 최대 스테이지까지 진행

### 2.2 난이도

| 난이도 | 최대 스테이지 | 적 강도 |
| --- | --- | --- |
| 쉬움 | 30 | 낮음 |
| 보통 | 40 | 중간 |
| 어려움 | 50 | 높음 |

### 2.3 배속

- 2단계: **천천히 / 빨리**
- 일시정지는 싱글에서만 지원 (멀티에서는 불가)
- 멀티에서는 호스트만 배속을 바꿀 수 있고, 모든 플레이어에게 같이 적용된다.

### 2.4 맵

- 유즈맵 방식: 적이 필드 둘레의 **순환 경로**를 따라 계속 돈다.
- 직업은 필드 가운데의 **고정된 칸**에만 배치할 수 있다. (6×3, 18칸으로 시작해 테스트하며 조정)
- 소환하면 빈 칸에 자동 배치되고, 끌어서 칸을 옮기거나 자리를 바꿀 수 있다.

### 2.5 승패 조건

- **스테이지 클리어**: 스테이지는 1분이 지나면 다음 스테이지로 넘어가고, 다 잡지 못한 적은 맵에 남아 쌓인다. 최대 스테이지를 깨면 클리어
- **패배**: 시작 라이프는 10이고, 맵에 남은 적이 한계 수(100마리 고정) 이상이면 10초마다 라이프가 1씩 줄어든다. 라이프가 0이 되면 패배

## 3. 직업 시스템

### 3.1 직업

- 검사, 궁수, 마법사처럼 직업마다 공격 방식과 역할(단일 딜, 광역, 둔화, 버프)이 다르다. (직업명은 예시)
- 사거리 안 적 중 타깃 규칙(가장 앞, 가장 체력 많음 등)에 맞는 적을 골라 자동으로 공격한다.

### 3.2 직업 획득

- **마나 결정으**로 직업을 소환한다. 어떤 직업이 나올지는 무작위다.
- 등급을 먼저 확률로 뽑고, 그 등급 안에서 직업을 뽑는다. 소환으로는 일반·고급·희귀만 나온다.
- 소환 비용은 1번에 마나 결정 6개, 적 처치 시 1마리당 마나 결정 2개를 얻고, 게임 시작 시 마나 결정 18개를 준다.

### 3.3 조합

- 직업 **2개, 3개, 4개**를 조합할 수 있다. (예: 검사 + 마법사 → 마검사)
- 조합에 쓴 직업은 사라지고, 결과로 상위 등급 직업이 나온다.
- 재료를 넣는 순서와 상관없이 같은 결과가 나오고, 같은 직업을 여러 개 넣는 조합도 가능하다.

### 3.4 히든 직업

- 특정 조합으로만 나오며, 조합표에는 히든 직업 이름과 재료 개수만 보이고 재료는 물음표로 표시된다.
- 한 번 만들면 도감에 해금되고 재료가 공개된다.
- 등급 순서와 별개이며, 히든 직업마다 강함을 따로 정한다.

### 3.5 등급

| 등급 | 얻는 방법 | 소환으로 획득 | 표시 색 (예시) | 적용 여부 |
| --- | --- | --- | --- | --- |
| 1. 일반 | 소환 | 가능 | 회색 | 1차 적용 |
| 2. 고급 | 소환, 일반 조합 | 가능 | 초록 | 1차 적용 |
| 3. 희귀 | 소환(낮은 확률), 고급 조합 | 가능 | 파랑 | 1차 적용 |
| 4. 영웅 | 희귀 조합 | 불가 | 보라 | 1차 적용 |
| 5. 전설 | 영웅 조합 | 불가 | 주황 | 추후 |
| 6. 신화 | 전설 조합 (특별 재료 포함) | 불가 | 빨강 | 추후 |
| 7. 초월 | 신화 조합 (특별 재료 포함) | 불가 | 금색 | 추후 |
| 히든 | 지정된 특수 조합만 (조합표에는 물음표로 표시) | 불가 | 검정 | 1차 적용 |

> 등급 이름과 표시 색은 가안이다.

## 4. 멀티플레이

### 4.1 방식

- 최대 4인, **개인 플레이 방식**: 각자 자기 맵에서 플레이한다.
- 목표는 경쟁이 아니라 **각자 클리어하는 협동**이다.
- 한 명이 방을 만들고, 나머지는 방 코드로 들어온다.
- 필드끼리 서로 영향을 주지 않으므로, 전투는 각자 기기에서 계산하고 필요한 것만 주고받는다.
- 패배한 플레이어는 방을 나가거나 남아서 다른 플레이어를 관전할 수 있다.

### 4.2 호스트

- 방을 만든 사람이 호스트가 되어 배속을 조절한다.
- 호스트가 나가면 방에 들어온 순서상 다음 사람이 호스트를 이어받는다.
- 새 호스트가 연결을 다시 만들고 나머지가 재접속하는 방식으로 구현한다. 넘길 상태는 현재 스테이지와 배속 정도다.

### 4.3 연결 끊김

- 끊긴 뒤 2스테이지 안에는 재접속할 수 있다.
- 2스테이지가 지나도록 돌아오지 않으면 탈락 처리한다.

### 4.4 추후 추가

- 멀티 전용 협동 퀘스트

## 5. 기술 스펙 및 개발 환경

### 5.1 기술 스펙

| 구분 | 사용 기술 | 용도 |
| --- | --- | --- |
| 엔진 | Unity 6 LTS (2D URP) | 게임 전체 |
| 언어 | C# | 게임 로직 |
| 입력 | Input System (신형) | 터치로 소환·배치·조합, PC 지원 시 마우스·키보드 추가 |
| UI | uGUI + TextMeshPro | 인게임 HUD, 도감, 메뉴 (가로 해상도 기준) |
| 연출 | DOTween (무료판) | 소환·조합 연출, UI 애니메이션 |
| 게임 데이터 | ScriptableObject | 직업 스탯, 조합표, 스테이지, 소환 확률 |
| 저장 | JsonUtility + 로컬 파일 (persistentDataPath) | 도감 해금, 난이도별 최고 도달 스테이지, 설정 |
| 적 이동 | 웨이포인트 순환 경로 | 마지막 지점에서 처음 지점으로 이어지는 루프 (NavMesh 불필요) |
| 성능 | UnityEngine.Pool.ObjectPool | 적·이펙트 재사용 |
| 멀티 네트워크 | Netcode for GameObjects | 호스트-클라이언트 동기화 |
| 방 만들기·입장 | Unity Lobby | 방 생성, 방 코드로 입장, 최대 4인 |
| 연결 중계 | Unity Relay | 전용 서버·포트 개방 없이 플레이어끼리 연결 |
| 플레이어 인증 | Unity Authentication (익명 로그인) | Lobby·Relay 사용을 위한 플레이어 ID |

### 5.2 주요 구현 방식

- **랜덤 소환**: 등급별 가중치 테이블에서 등급을 먼저 뽑고, 그 등급 안에서 직업을 뽑는 2단계 방식. 확률은 ScriptableObject에서 조정
- **조합 판정**: 조합표를 게임 시작 시 Dictionary로 만들고, 재료 직업 ID를 정렬해 이어 붙인 문자열(예: `archer|mage|mage`)을 키로 찾는다
- **히든 직업**: 일반 조합과 같은 조합표에 두되 `isHidden` 표시로 구분하고, 해금 전에는 조합표 화면에서 재료를 물음표로 보여준다
- **직업 공격**: 공격 방식은 직업 데이터에 연결된 컴포넌트로 나눈다
- **스테이지·난이도**: 난이도마다 최대 스테이지 수와 적 체력·속도·보상 배율을, 스테이지마다 등장 적·보스를 ScriptableObject로 정의
- **진행 속도**: `Time.timeScale`로 배속과 일시정지를 처리. 게임 로직은 `Time.deltaTime` 기준, UI 연출은 unscaled time 사용
- **화면 방향**: Player Settings에서 Landscape Left/Right만 허용. 기준 해상도 16:9(1920×1080), 더 긴 화면은 Safe Area로 대응
- **PC 확장 대비**: 입력을 Input System 액션 단위로 만들어 터치와 마우스를 같은 코드로 처리
- **호스트 이전**: Netcode for GameObjects는 호스트 이전을 기본 지원하지 않으므로, 새 호스트가 Relay 연결을 다시 만들고 나머지가 재접속
