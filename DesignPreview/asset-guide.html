게임 에셋으로 넣는 방법

이 캔버스의 이미지는 미리보기 크기라서 흐릴 수 있어요. 실제 소스에 넣을 때는 아래 순서로 진행해요.

가능한 것

  • 고해상도 원본: 각 카드의 "Canva 원본" 링크에서 큰 이미지를 받을 수 있음
  • 배경 제거: Canva 배경 제거 기능으로 투명 PNG로 만들기
  • 잘라서 크기 맞추기: 시트에서 타일·버튼을 하나씩 잘라 64px 등 게임 규격으로 줄이기. 픽셀아트는 흐려지지 않게 최근접 보간(Nearest Neighbor)으로 줄여야 함

주의할 점

  • AI로 만든 픽셀아트는 격자가 정확하지 않음. 픽셀 크기가 들쭉날쭉하거나 타일 경계가 살짝 어긋날 수 있음
  • 그대로 64px로 줄이면 선이 뭉개지거나, 타일을 이어 붙일 때 이음새가 보일 수 있음
  • 자르기·줄이기는 명령어 실행이 필요하므로 작업 전에 먼저 확인받고 진행

권장 방법 (둘 중 하나)

  1. 시트에서 잘라 손보기: 시트에서 잘라낸 뒤 Aseprite 같은 픽셀 편집기에서 이음새와 외곽선을 살짝 손봄
  2. 쓸 것만 하나씩 따로 생성 (더 안정적): 예) "64×64 돌길 직선 타일 1개, 이음새 없이 반복 가능"처럼 개별 에셋으로 생성

진행 순서

  1. 시안 방향 확정
  2. 필요한 타일·버튼 목록 정리
  3. 개별 에셋으로 생성 (또는 시트에서 잘라 손보기)
  4. 배경 제거 → 게임 규격으로 줄이기 → 소스에 반영
